# Product flow — development decisions, not production release
- Multi-select industry and work intent. No automatic paid addon activation.
- One assistant can cover multiple industries/jobs. Additional assistant only for a separate brand, public link, knowledge or voice; current entitlement provides one extra profile and shares quota/calendar.
- Free real AI test remains one reply. Static previews are free; paid quota or invited trial for continued testing. Education is separately charged on existing credits. Direct staff chat uses no AI replies; new public chats may default to staff, per-thread switch remains available.
- Staff education: select real staff replies, redact/review, confirm permission, use existing education estimate/reservation/approval; no automatic learning or charge.
- Existing subscription quote displays previous paid monthly price, new monthly price and positive remaining-cycle estimate. Sandbox checkout remains full nominal monthly amount; actual production prorated upgrade or next-cycle downgrade requires verified Polar product update/webhooks and explicit confirmation. Do not present test orders as actual charges. Preserve original paid quota and cycle.
- External AI knowledge import is business-context migration, not a copy of an account or model. No public full-account history sync established. Free file preflight counts and title-only category hints; no raw archive persisted by preflight. The user can also create a focused business summary in ChatGPT and use ordinary paid education. Full history migration should separately charge for the import service plus normal analysis credits; do not set final tariff until payment and data scale tests. The separate prototype has 19,900 KRW sandbox entitlement; the product branch previously documented 9,900 KRW as a proposal. Do not silently merge conflicting rates.
- Future import flow: scoped permission, selected titles/date, secret/PII review, max credit quote, separate one-time fee, bounded batches, idempotency, retries, approval, version restore. Actual classification of whole archives is not free. Multiple JSON exports and large archives require further work; don't raise limits without load tests.
- Real payment, full migration integration, paid feature draft setup, and end-to-end/browser tests are outstanding. No production deploy.
