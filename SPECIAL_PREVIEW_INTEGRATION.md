No raw FAQ answers, drafts, customer history, provider usage, purchases or automatic training changes. Run python -m pytest -q tests/test_special_preview_api.py after merging the latest local app; run scripts/special_offline_checks.py separately. JS syntax validated, Python and browser tests not executed in this connector session.
