# Retrieval pipeline integration
Connects incremental indexing, scoped hybrid ranking, and optional query-vector caching through one server-only adapter. Default off; no live embedding provider, no production app hookup. Refreshes require explicit record and byte bounds; each cache miss requires trusted authorization, and actual usage settlement remains the caller's responsibility. On failed refresh the prior index is discarded. Do not share an instance across workspaces or concurrently mutate it. Only cache queries approved by privacy policy. Run the offline checks using the script below; no external services are needed.
