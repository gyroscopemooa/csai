# Memory migration — sandbox stage
- A paid local sandbox order is tied to the chosen brand; 19,900 KRW test fee and ordinary education credits are separate.
- JSON preflight and selection are on-device. Selected messages are extracted into up to 120 bounded text batches. Each batch is reviewed, submitted with permission, quoted by the existing education estimator, and explicitly analyzed. No auto publish or charge.
- Same sanitized batch digest and paid order reuses the quote or finished result; expired/failed attempts can be re-quoted. Existing credit reservation/settlement is reused.
- Batch source is stored only as needed for a quote; failed and replaced sources are cleared. Unused estimated source retention needs cleanup worker verification.
- No real payment, automatic account syncing, large ZIP direct migration, background mass processing or cross-device browser draft recovery. The 19,900 fee and 120-batch policy are provisional until load and cost verification.
