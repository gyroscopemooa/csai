# SPECIAL orchestration pilot

Links existing entitlement checks, usage reservation/settlement and trusted injected read-only adapters. Default disabled; not imported into the live app, no real checkout, provider call or customer credit changes. Job IDs, limits, current period, grant verification and adapter registry must originate from authenticated server state. Never expose this module directly as an HTTP API. Unknown execution retains the reservation; never retry automatically. Adapter-reported cost overruns must be reconciled, not hidden. The customer report exposes only complete curated-case check counts, not semantic accuracy or internal cost. Production still requires durable job-result persistence, transactional entitlement enforcement, authorized provider adapters and full integration testing. Run python -m unittest discover -s tests -p test_special_orchestration.py.
