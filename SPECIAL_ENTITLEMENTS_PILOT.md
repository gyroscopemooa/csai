# SPECIAL entitlement and spend ceiling foundation

Separate proposed package IDs and prices. Existing catalog, checkout, subscriptions and credits are untouched. Quotes are unavailable for purchase; grants default off. No payment provider, DB migration, grant issuance, transaction ledger or API calls. A future trusted billing adapter must verify paid orders, cancellation/refund/expiry, base-plan eligibility, feature rollout and workspace identity; atomic reservations, credit debits, reconciliation and measured full unit economics remain required. Cost ceiling uses net revenue and actual attributable costs supplied by the server. It is not a guarantee of margin or protection against concurrent spending. Test: python -m unittest discover -s tests -p test_special_entitlements.py.
