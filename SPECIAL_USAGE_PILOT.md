# SPECIAL usage ledger pilot

Standalone SQLite reference only; no app import, checkout, real credits or provider calls. Instantiate only against an isolated local file. Integer credit and cost units must be fixed by a trusted billing adapter. Atomic reservations and settlement, scope and replay checks, unused allocation release and actual-cost overrun accounting. Never settle zero after an uncertain provider execution; keep the reservation until reconciliation. A replay returning False never authorizes a second execution. No automated retries. Production requires integration with the shared database, verified payment and entitlement, authorization, period policy, durable execution/reconciliation, refunds, actual provider budgets and measured unit economics. Run python -m unittest discover -s tests -p test_special_usage.py.
