# SPECIAL evaluation record store
Isolated SQLite pilot, not production DB. Persists only completed trusted case outcomes and version metadata, no raw prompts or internal cost. Scoped reads use SPECIAL entitlements; duplicate IDs are idempotent or rejected if inconsistent. Explicit scoped purge is for a trusted deletion worker. Production persistence, authenticated routes, retention scheduling, source provenance, trusted completion timestamps and authorization remain unconnected. No API cost or payment changes. Run python -m unittest discover -s tests -p test_special_evaluation_store.py.
