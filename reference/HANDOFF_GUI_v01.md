# GUI / Codex 이어서 작업 명령

현재 폴더는 CS AI의 실행형 로컬 MVP다. `README.md`, `reference/DEVELOPMENT_PROMPT.md`, 기획 DOCX, 기존 UI 19종, `verification/`, `catalog.json`, 테스트를 먼저 확인한다. 이전 HTML 참고용 프로토타입이 아니라 `app.py`, `ai.py`, `store.py`, `web/`의 실제 작동 코드를 기준으로 한다. 사용자 승인 없이 가격/유료 옵션/디자인/모바일 우선 정책을 변경하지 않는다.

1. 로컬에서 의존성 설치, `python run.py` 실행, API 테스트 및 일반 브라우저 직접 HTTP 테스트. 오류 수정. 이미 동작하는 기능은 보존. 최초 테스트 1회, 300회 9,900원, 교육 크레딧/부가 기능/발송량 가격을 확인.
2. 환경변수 필요 목록과 연결 순서를 안내하고 기존 계정이 있으면 재사용. 비밀키는 `.env` 또는 시크릿 저장소에만 입력. 키를 커밋/로그/문서로 노출하지 말 것. Google OAuth 및 OpenAI Sol/Luna 실제 연결 확인. 실제 API 사용 비용과 자료 개인정보 처리에 유의.
3. 운영 구조로 확장: Supabase Auth/Postgres/RLS 및 원자적 예약/차감 RPC. `supabase/migrations/001_foundation_DRAFT.sql`은 출발점이며 운영 마이그레이션이 아님. 데이터 스키마와 API 계약을 검증 후 이전. Next.js로 이전할 필요가 있으면 기존 화면·동작·테스트 유지하며 단계별 진행. 신규 아키텍처로 임의 재작성하지 말 것.
4. 실제 파일 학습 품질 검증, 대량 자료 분할/변경분, 출처·충돌 처리, 버전 롤백, 승인 전 미반영, 정형 안내 무과금, 장기 대화 요약/RAG, 비용·실패·재시도·중단 복구. 현 OCR/이미지 분석은 API 키 없을 때 의미 분석 미지원. 비용을 테스트 자료로 측정.
5. 네이버 톡톡 공식 API, 카카오 채널 스킬/콜백, 구글 캘린더, Resend, 웹 푸시, 알림톡/SMS를 업체별로 연결. 외부 인증 정보 암호화/웹훅 검증/중복 처리/비동기 작업/전송 정책 확인. 상용 계약과 승인 전에는 실제 판매 활성화 금지. `integrations/channels.py`는 포맷 참고용이다.
6. 일정 관리: 업체 양식·대화 수집·고객 확인·확정/대기 상태 흐름을 유지. 다중 작가/담당자/버퍼/수용량, 예약 변경·취소 고객 인증, 외부 일정 충돌, 알림/승인 이력 확장. 외부 결제 완료를 고객 발언으로 추정하지 않음. 스마트스토어/마이리얼트립 등은 공식 구매처 링크 안내만.
7. 실제 PG 연동 시 SKU/서버 카탈로그/서명 검증/결제 이벤트 멱등/갱신·만료/환불 처리. 실제 승인 없는 결제, 외부 유료 서비스 구매, 사업자 약관 동의, 도메인 구매를 하지 말 것. 무료와 유료 권한을 구분. 패키지 포함 범위 검토. 준비 중 기능은 실제 구매하지 못하게 함. 로컬 데모 권한 우회 완전 비활성화.
8. 보안/개인정보/운영 안정화 및 테스트. E2E PC·모바일, 타 업체 접근 차단, 첫 무료 테스트, 교육 비용, 중복 예약, 결제 미확인, 실패 복구, 외부 webhook, 로딩/빈 상태/접근성. 실제 호출과 mock 테스트 구분. 검증 결과와 미구현 항목을 기록.
9. GitHub가 없으면 로컬 Git init 후 초기 커밋. 원격 저장소와 배포 환경은 사용자의 기존 계정 연결/명시적 승인에 따라 생성. 공개 배포 전에 보안/실연동 체크리스트를 완료하고 기존 테스트 데이터는 이관하지 말 것. 커밋/푸시/배포 성공 여부를 정확히 보고.

현재 코드에서 우선 필요한 작업을 순서대로 수행하고, 필요한 실제 계정 인증/결제/권한에서만 사용자에게 확인한다. 구현하지 않았거나 실제로 검증하지 못한 기능을 완료로 표시하지 않는다.
